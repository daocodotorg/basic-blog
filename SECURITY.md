# Security

If you believe you have found a security vulnerability in this project, please report it responsibly instead of opening a public issue.

**Preferred:** use [GitHub Security Advisories](https://github.com/daocodotorg/basic-blog/security/advisories/new) for this repository so maintainers can coordinate a fix and disclosure.

Include:

- A short description of the issue and its impact
- Steps to reproduce (or a proof of concept), if safe to share
- Affected versions or commits, if known

We will acknowledge receipt as soon as we can and work on a fix and release timeline.
